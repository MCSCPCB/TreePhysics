# 树木识别、砍伐与倒伏物理验收

## 准备

1. 运行 `npm test`，再运行 `npm run build`，加载 `packs/TreePhysics/BP` 与 `packs/TreePhysics/RP`。
2. 必须新建世界；本版本不迁移没有根标记的旧区块。
3. 正常破坏原木会尝试树木物理；潜行破坏用于明确绕过物理。

## 当前判据

- 世界生成的直立树和原版倒木地物应在砍断后只让无根组件成为物理装配体。
- 玩家种下并长成的树使用同一地物定义，应与世界生成树相同。
- 玩家放置的原木、木块或根会留下区块级记录；目标原木结构命中任一记录时整棵不触发。
- 玩家放置或持久化的树叶、玩家放置的树上附件留在世界中，但不得阻止其余自然树结构生成装配体。
- 相邻树冠的同类叶片应在派生叶距的距离岭处分开；2×2 巨型树的全部主干属于同一
  距离源，叶片归属不得把巨型云杉拆成四棵树，也不得反向拒绝其原木组件。
- 在自然根标记上搭建并连接成人工树形建筑，也不得借用该标记触发物理。
- 砍树后不再支撑树干的根标记恢复为生成前的泥土、砂土、泥巴、缠根泥土或灰化土。
- 5 种原版倒木地物具有相同根标记并支持水平分段；`jungle_bush_feature` 仍不进入树装配流程。
- 叶片从目标树各原木组件向外作最多 6 格的同叶种洪泛；不推断具体 Feature、树型或理论叶片数。
  树冠重叠时允许带走少量邻树叶片，但这种歧义不得导致目标树不生成。
- 同种树木的枝条或树干以 26 邻域相接时，应先按自然根标记的加权最短路径分离；
  砍伐其中一棵仍须生成装配体，等距原木边界和邻树原木必须留在世界。
- 相邻的自然根标记按同一 2x2 主干根簇处理；华丽橡树式多分支原木和约 31 格高的
  2x2 巨型云杉原木不得被树型分类或扫描预算拆散。
- 大面积同族树冠相连、原始叶片候选超过 1024，或同族原木网络超过旧 4096 限制时，
  砍伐目标树仍须生成装配体。单组件超过 6144 方块时必须保留全部原木，再按到原木
  的洪泛距离舍弃装不下的叶片，不得因叶片数量静默放弃整棵树。
- 苍白橡树的嘎吱之心必须作为原木结构节点进入装配体；`moss_carpet` 与
  `pale_moss_carpet` 不得进入装配体。

## 倒伏物理

- 在普通地面、冰面、泥巴、蜂蜜块上分别放倒相近树木，冰面应明显更易滑动，
  泥巴摩擦较低，蜂蜜块应明显阻滞运动。
- 让倒木撞击黏液块，树干应产生明显回弹；撞击普通方块不应出现同等回弹。
- 将树木砍向水面，树干与树叶应按浸没程度获得浮力并受到水阻，不应像空气中
  一样持续自由下沉。当前模型不模拟水流推动与波浪。
- 树冠叶片接触地面、墙体等实体碰撞形状时应逐批破碎并产生对应原版掉落，但不得
  对装配体产生阻挡、摩擦、回弹或短暂停顿。
- 装配体树叶必须保留用于接触检测的合并传感器形状；破碎后对应形状应立即消失，
  不能留下不可见接触区域。
- 一片叶片破碎后，已经无法经 26 邻域叶片连接到任何剩余原木的叶片和植物附着物
  必须在同一批次破碎并生成原版掉落，不能继续悬空依附于装配体。
- 主干侵蚀只能对主干具有连续完整 `2x2` 横截面的巨型丛林树启用；砍伐层允许缺少触发
  方块。普通丛林树和其他树木即使方块很多或叶片性能档下降也不得误用丛林侵蚀。
- 巨型云杉和巨型松树只能在连续完整 `2x2` 主干的底部六层以上生成横断裂口；普通单格云杉、
  过矮结构和其他树种不得启用。裂口必须优先选择靠近最强碰撞点的预设断面，并在开启后先完成
  同一断面，不能把 `2x2` 主干逐列削成长期存在的细柱。
- 华丽橡树只能把连续单格主干以外、水平伸展至少两格的真实分支纳入破碎；完整主干必须
  永久受保护。直立普通橡树、短侧结橡树、白桦、金合欢及其他单格树种不得误启用。
- 巨型丛林树必须先破碎主干外分支，再从靠近树冠处向下形成少量受约束随机裂口。
  同一 tick 的多接触只累计最强冲击；低于 `1.75` 的静止或微抖动接触不得累计损伤。
  每次有效碰撞最多执行一个批次，同时未完成裂口不得超过两个。
- 主干一侧破碎后，只删除真实失去 26 邻域原木连接的远端结构；仍有替代连接时必须继续
  保留。所有连通性均以真实 fragment 渲染锚点所在的受保护基座为唯一保留源，保护原木
  永不得破碎。断连原木、失去支撑的树叶和附件必须并入同一删除，不得创建子装配体、
  额外刚体或显示实体。原木断裂粒子最多采样 32 个，掉落物仍须数量守恒。
- 藤蔓、垂根、红树胎生苗和苍白垂苔使用整格无阻挡传感器并按阈值 0 破碎，
  但实际运动不得产生阻挡、摩擦或回弹。
- 自然蜂巢必须作为完整实体碰撞体随树运动；可可果按年龄和朝向使用原版局部小碰撞盒。
  两者在碰撞速度低于 4 时保持完整，达到 4 后从装配体破碎并生成原版掉落。砍伐
  装配树木时原世界蜂巢只直接置为空气，不应生成蜜蜂；装配体蜂巢真正破碎时，按
  `honey_level` 的 0/1-2/3-4/5 分段分别生成 0/1/2/3 只蜜蜂；蜂巢保持到装配体
  最终结算时也按相同规则生成，但已经提前破碎的蜂巢不得重复生成。
- 所有世界树叶必须参与接触检测；只有非持久且不在人工记录中的自然叶片使用
  无阻挡传感器并能够破碎。人工或持久叶片保持实体碰撞且不被树木物理破坏。
  落叶堆、草、蕨、花和树苗不能支撑倒木，也不会因倒木覆盖而破碎。
- 倒伏树干以足够速度撞击世界后，未直接接触地面的叶片应每 2 tick 从距离 7
  向树干方向逐层凋落；紧邻树干的距离 1 叶片按原项目规则保留。
- 树干高速撞击冰、树叶、竹子、瓜、仙人掌、睡莲、蜂巢或可可果等 Sable/Tree
  Physics 易碎方块时，目标方块应破碎并生成原版掉落；冰在有承托时变为水。

## 伤害与结算

- 倒木原木撞到玩家或有生命值的生物时，应按原木局部速度造成伤害并向外击退；
  同一实体连续接触时最多每 4 tick 受伤一次。
- 地面的已有掉落物、树叶产生的掉落物和 `tree_physics:physics_block` 显示实体不得
  受到树木伤害，也不得在整树结算时被删除。
- 正常条件下，每根原木的累计 sleep 时间应为空手/非斧 60、木斧 30、石斧 15、
  铜斧 12、铁斧 10、钻石斧 8、下界合金斧 7、金斧 5 tick；总时间乘以装配体
  原木数量，效率附魔会按原版公式进一步缩短时间。
- sleep 期间再次滑动、弹起或受碰撞唤醒后，结算计时应暂停；再次休眠时从先前
  累计值继续。
- 原木破碎事务成功后，总 sleep 阈值必须按实际删除的原木数同步缩短；每根原木成本只在
  砍伐时计算一次。叶片或附件破碎不得改变原木计时，强退恢复后的阈值必须与正常提交一致。
- 睡眠倒木被另一装配体撞击、附近支撑方块被放置/破坏/爆炸/活塞移动，或玩家
  击打其显示方块时必须立即唤醒；不能在第一次 sleep 后永久静止。
- 红石改变碰撞形状、方块燃烧/融化或自然生长等没有玩家事件的物理环境变化，
  应由低频 `getBlock` 环境核验在约 1 秒内唤醒；无碰撞草花变化不应造成唤醒。
- 累计 sleep 达到阈值后，装配体应消失，所有仍存在的方块按砍伐时工具和原版
  LootTable 转化为掉落物；已经破碎的树叶不得重复掉落。
- 空手或持物左键命中倒木时，应按 Sable 有效质量、直立度加成和 3 tick 冷却在
  真实命中点施加冲量；向下攻击的垂直分量应明显衰减。右键仅在手持物品时可开始
  牵引，命中树木时不应同时使用或消耗该物品；抓取后移开视线或短暂遮挡不得松手，
  松开、切槽、物品消失、超距、死亡或换维度必须结束牵引。单原木和大树均应使用
  每轴最大 120 的线性力、最低 2 格目标距离和 4.5 的角阻尼。

## 重载与加载域

- 在倒木运动或休眠未达标时执行脚本重载，玩家仍在附近时应按保存的位置、旋转、
  线/角速度、剩余树叶和衰减进度恢复，不应复制显示实体。
- 在原木断裂事务落盘后、装配体删除前强制重载，必须先补齐带确定性 tag 的断裂掉落，
  再只恢复过滤后的唯一装配体；同一事务重试期间收到的新碰撞必须留到下一批处理，
  不能混入已落盘键集。事务携带的目标 sleep 阈值必须与过滤后的原木结构一并提交。
- 先累计部分 sleep tick，再唤醒或重载；恢复后只保留重载前已累计值，关闭世界的
  现实时间不得推进结算计时。
- 让运动中的倒木接近玩家加载边界，或让玩家持续远离倒木；装配体应在当前区块仍
  可读时转换为正常 LootTable 掉落，不应冻结、穿入未加载区块或提前一大段距离消失。

## 当前边界

世界在没有最后一个脚本 tick 的情况下突然关闭时无法安全生成掉落，此时保存状态，
下次有附近玩家加载后恢复装配体。
浮体物理是逐块中心采样的轻量模型，不模拟水流、流体体积守恒或造波。

性能复核可运行 `npm run bench:physics`。回退验收的当前同机结果为：primitive
10 体约 `1.85ms`、32 体约 `5.68ms`；完整树冠 10 棵、1230 方块、170 shape
约 `6.75ms`；10 棵休眠树包含环境核验时约 `0.27ms`。
