# 拖拽、活塞与爆炸物理计划及实施报告

## 1. 目标与完成状态

本轮完成以下三项功能：

1. 右键装配体后锁定牵引，再次右键释放；不再依赖持续使用心跳。
2. 活塞扩展对真实接触的装配体施加有质量和冲量上限的接触冲量。
3. TNT 及其他 Bedrock 爆炸事件对现有装配体施加带距离衰减、遮挡和偏心扭矩的径向冲量。

实现不创建任何新物理实体、渲染实体、掉落物、粒子或声音，不改变 Cannon 子步数、树木
runtime collider、fragment 布局、休眠阈值、掉落物合并和生命周期策略。

## 2. 拖拽语义与性能

`TreePlayerInteractionController` 的状态为每玩家至多一个锁定会话：

- 无会话时，`beforeEvents.itemUse` 射线命中装配体后建立锁定。
- 有会话时，下一次有效 `itemUse` 只释放，不允许同一事件重新获取。
- 同一游戏刻的重复输入会被去重。
- `itemStopUse`、`itemReleaseUse`、`itemCompleteUse` 和 `itemStopUseOn` 不再负责释放。
- 玩家死亡、离开、重生、换维度、旁观、切换槽位、替换手持物、装配体失效或距离超过 7 格时释放。

抓取距离 `2-2.5`、弹簧刚度 `240`、阻尼 `30`、每轴最大力 `120` 和角阻尼 `4.5` 保持不变。
每个维度只有一个活动拖拽子步回调；玩家头部、视线、模式和物品每游戏刻只采样一次，三个
物理子步复用目标点。位置误差不超过 `0.01`、点速度不超过 `0.02`、角速度不超过 `0.02`
时不提交力或扭矩，使保持锁定且已稳定的装配体可以重新休眠。

## 3. 外力批处理

`AssemblyExternalEffectsController` 没有常驻 `runInterval` 或物理子步回调。首个事件只安排一个
`system.run`，同刻事件按维度合并，结算完成后清空全部临时状态。

每个维度每批最多读取一次装配体列表。活塞联合包围盒在批次开始时预计算，装配体只有通过
AABB 宽相后才进入窄相；冲量累加器也只在真实接触后创建。同一装配体一批最多提交一次线性
冲量和一次角冲量。

装配体接触查询复用 `PhysicsAssembly` 已有的局部方块哈希。爆炸球体转换到装配体局部空间，
活塞扫掠体只枚举其局部覆盖网格，不为大型树构建完整世界坐标快照。活塞使用 OBB-AABB SAT
排除旋转装配体包围盒空角；爆炸查询最近的真实方块表面，因此不会命中稀疏巨型树 AABB 中的
空白区域。

高并发限制：

- 每装配体每批最多处理 16 个宽相命中的活塞事件。
- 每装配体保留距离最近的 16 个爆炸源。
- 每装配体每批最多执行 4 次 Bedrock 世界遮挡射线。
- 同位置、同半径爆炸合并，数量只改变有上限的强度系数。
- 批次线速度增量上限为 `6 block/s`，角速度增量上限为 `1.5 rad/s`。

## 4. 活塞行为

活塞方向沿用 Bedrock `facing_direction` 六向映射。接触源包括活塞臂位置和事件报告的附着
方块位置，每侧增加 `0.08` 接触裕量，运动前方增加 `0.16` 裕量。

扩展冲量为：

```text
delta = max(0, 6 - dot(contactVelocity, pistonDirection))
J = min(effectiveMassAtContact * delta, impulseCap)
```

普通活塞 `impulseCap=12`；最前附着方块是黏液块时为 `16`。冲量在真实接触点聚合为线性冲量
和 `r x J` 角冲量。收缩只唤醒真实接触的响应碰撞体，不隔空吸附；黏性活塞也不把未建立连接
的装配体强行拉回。树叶的 `collisionResponse=false`，因此仅接触树叶不会被活塞误推。

人工树注册表仍标记所有可用的活塞附着方块。无效活塞组件或移动中失效方块只跳过本次效果，
不会留下半完成物理状态。

## 5. TNT 与爆炸行为

`afterEvents.explosion` 只处理确认发生且未被其他行为包取消的爆炸，并立即保存来源位置、维度和
受影响方块坐标。如果来源有效，爆心使用来源实体位置；否则使用受影响方块中心。半径为最远受影响方块距离加 `1.25`，限制在
`2.5-8`；空中爆炸使用 `4.25`。

爆炸冲量为：

```text
falloff = pow(max(0, 1 - distance / radius), 0.68)
J = falloff * countScale * min(
  effectiveMassAtContact * max(0, 7 - outwardPointSpeed),
  6 * pow(totalMass, 2 / 3)
)
```

方向加入 `0.4` 向上偏置。冲量作用于最近装配体方块表面，偏心扭矩来自 `r x J`，不写入合成
随机角速度。爆炸允许作用于可碰撞但无碰撞响应的树叶，使树冠内 TNT 仍能推动树木；完整世界
方块遮挡通过有预算的 `Dimension.getBlockFromRay` 检查。

原 `blockExplode` 的逐方块人工树删除逻辑保留，逐炸毁方块 `wakeBodiesNear` 被一次爆炸批处理
替代。不生成物理碎片，不删除装配体内部方块，不改变原版爆炸破坏、掉落、声音或粒子。

## 6. 验证结果

- `npm test`：20 个测试文件、284 项全部通过。
- `npm run verify:release-build`：正式构建已通过并输出到 `packs/TreePhysics/BP/scripts`。
- `npm run bench:physics`：全部既有物理、生命周期、装配和巨型树基准通过。
- 64 个同点爆炸：1 次调度、1 次维度扫描、1 次接触测试、1 次身体冲量提交。
- 64 个同刻活塞候选：1 次调度、1 次维度扫描、最多 16 次窄相、1 次身体冲量提交。

新增专用 Node/Vitest 微基准，测试对象为 980 方块稀疏树：

| 场景 | 平均耗时 |
| --- | ---: |
| 爆炸局部接触 | `0.2212 ms` |
| 13 个活塞源窄相 | `0.1736 ms` |
| 64 个同点爆炸完整合并批次 | `0.2871 ms` |

Node/Vitest 结果只用于同机结构和回归比较，不能替代 Bedrock 客户端 TPS/FPS。发布前仍需实机
验证右键事件、六向活塞、黏液块、空中 TNT、墙体遮挡、连锁 TNT、静止/运动巨型丛林木以及
玩家死亡、换维度、换槽位的自然释放。验收时应确认外力触发后的持续成本与现有左键唤醒同一
装配体一致，并确认实体数量没有增长。
